# Кабельный дизайнер (cable-designer)

Настольное приложение (Electron + React) для оформления кабельной документации:
схема кабеля с жилами/наконечниками/датчиками, таблица жил, лист А4 с ГОСТ-рамкой,
печать и экспорт в PDF.

## Стек

- Electron 44 (точка входа `electron/main.cjs`, preload `electron/preload.cjs`)
- React 19 + TypeScript + Vite 7
- Tailwind CSS 3.4 (конфиг `tailwind.config.js`, `postcss.config.js`)
- Сборка: `tsc -b && vite build` → единый IIFE-бандл в `dist/`

## Структура

```
resources/app/
├── dist/                 # собранное приложение (то, что грузит Electron)
├── electron/
│   ├── main.cjs          # окно, IPC: project:save / project:saveAs / project:open,
│   │                     # защита от закрытия с несохранёнными изменениями
│   └── preload.cjs       # contextBridge → window.cableFiles
├── src/
│   ├── pages/Home.tsx    # вся логика редактора + файловые операции
│   ├── components/
│   │   ├── CableSvg.tsx  # SVG-схема кабеля (кривые Безье, датчики, наконечники)
│   │   └── SheetA4.tsx   # лист А4, рамка, штамп
│   ├── types/cable.ts    # Cable / Wire / Project, фабрики, пагинация листов
│   └── index.css         # Tailwind + стили листа А4 и печати
├── tailwind.config.js    # ОБЯЗАТЕЛЕН для сборки (см. «Подводные камни»)
├── postcss.config.js     # ОБЯЗАТЕЛЕН для сборки
└── package.json
```

## Возможности

- Кабели: 1–24 жилы, цвета, наконечники (библиотека в `types/cable.ts`),
  маркировка общая или отдельная на каждый конец, произвольные столбцы таблицы.
- Стороны: свободные концы или датчик (подписи рисуются поверх проводов с ореолом).
- **Перемычки (гирлянды)**: от конца любой жилы — N перемычек со своей маркировкой
  и наконечником; галочка «перемычка» превращает провод в точку разветвления
  (рекурсивно, модель `Jumper` в `types/cable.ts`). Раскладка по вертикальным
  слотам (`wireSlots`/`jumperLeaves`) — дуги не пересекаются.
- **Undo/Redo**: Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z), кнопки ↶/↷ в шапке панели.
  История — снапшоты проекта в `Home.tsx` (commit/pastRef/futureRef), лимит 100.
  В полях ввода не перехватывается (там работает отмена текста браузера).
- **Массовые операции с жилами**: чекбоксы в таблице жил → назначение цвета
  и наконечников сторон А/Б всем выбранным сразу.
- **Дублировать** — полная копия выбранного кабеля (новые id кабеля/жил/столбцов,
  `customKey` столбцов сохраняется — по нему привязаны значения `wire.custom`).
- **Открыть / Сохранить / Сохранить как** — проект в JSON (`app: "cable-designer"`,
  `version: 2`); при открытии выполняется миграция старых полей (`migrateProject`).
- Защита от потери данных: флаг `dirty` в `Home.tsx`, индикатор «не сохранено»,
  confirm при открытии другого файла, системный диалог при закрытии окна
  (главный процесс читает `window.__cableIsDirty()` через `executeJavaScript`).
- Автосохранение черновика в `localStorage` (ключ `cable-designer-project-v2`).
- Печать/экспорт PDF: стили `@media print` в `index.css`.

## Сборка и запуск из исходников

```bash
npm install
npm run build        # tsc -b && vite build → dist/
npx electron .       # запуск из исходников
```

Пересобранный `dist/` и папку `electron/` достаточно скопировать в
`release/cable-designer-win32-x64/resources/app/` — готовый exe подхватит их.

## Подводные камни (важно!)

1. **`tailwind.config.js` и `postcss.config.js` нельзя удалять.** Без них сборка
   проходит «успешно», но Tailwind не компилируется: в бандл попадают сырые
   директивы `@tailwind`, и приложение теряет ВСЮ стилизацию.
2. **`node_modules` не нужен для работы приложения.** Бандл в `dist/` самодостаточен
   (React и всё остальное внутри). После сборки `node_modules` можно удалить —
   так папка релиза копируется в разы быстрее (десятки тысяч файлов → ~150).
   Для следующей пересборки: `npm install` (~1 мин).
3. **`ELECTRON_RUN_AS_NODE`.** Если в окружении терминала выставлена эта переменная,
   `cable-designer.exe` молча завершается сразу после старта. Запускайте с
   очищенной переменной (`env -u ELECTRON_RUN_AS_NODE` / `set ELECTRON_RUN_AS_NODE=`).
   На двойной клик по exe это не влияет.
4. **Отладка:** запуск с `--remote-debugging-port=9222` даёт CDP-доступ
   (`http://127.0.0.1:9222/json`) — удобно для автотестов и скриншотов.
5. **Компоненты внутри компонентов.** `SideEditor` вынесен на уровень модуля:
   вложенное определение создавало новый тип компонента на каждый рендер,
   и поля ввода теряли фокус после каждой буквы. Не возвращать обратно внутрь `Home`.

## Формат файла проекта (.json)

```json
{
  "app": "cable-designer",
  "version": 2,
  "docNumber": "АНК 601Н-45 00 00 МЭ",
  "cables": [ { "id": "…", "designation": "…", "cores": 4, "wires": […], "columns": […], … } ]
}
```

Совместимость: при открытии недостающие поля кабеля дополняются значениями
по умолчанию (миграция v1 → v2). Файл без массива `cables` отклоняется
с сообщением об ошибке.
